Where to start

Designing a screen

Work in the Figma file and use only its components and Color tokens.

  • Start every screen on bg/screen.
  • Pick one Primary button per screen.
  • Check the Guidelines before adding a new token or component.
Read the rules

Building in Flutter

Copy the generated lib/theme/ folder into the app and read every value from it.

  • Colours from context.colors.
  • Sizes from AppSpacing and AppRadius.
  • Text from AppTypography.

Principles

PrincipleWhat it means in practice
Tokens, not valuesEvery colour, size and text style comes from a named token. That is what makes Dark mode and future rebrands a token change, not a redesign.
Even numbersFont sizes, line heights, spacing, radius and component sizes are even: 2, 4, 6, 8 and so on.
Readable in three scriptsEnglish renders in Roboto; Gujarati and Hindi fall back to Noto Sans at the same size and line height.
Accessible in both modesText keeps at least 4.5:1 contrast and icons and borders at least 3:1, in Light and in Dark.
Small and extendableA short list of tokens and components that covers today's screens, with a clear path for adding more.
