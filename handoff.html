Flutter setup

  1. Copy the theme filesUnzip the package and copy lib/theme/ into the app. Requires Flutter 3.22 or newer (Dart 3). Run dart format lib/theme afterwards.
    Dart
    import 'package:your_app/theme/theme.dart'; // exports every theme file
  2. Bundle the fontsDownload Roboto, Noto Sans Gujarati and Noto Sans Devanagari from Google Fonts (use the files in each static/ folder) and put them in assets/fonts/. Merge this into the existing flutter: section; the family names must match exactly.
    pubspec.yaml
    flutter:
  fonts:
    - family: Roboto
      fonts:
        - asset: assets/fonts/Roboto-Regular.ttf
          weight: 400
        - asset: assets/fonts/Roboto-SemiBold.ttf
          weight: 600
        - asset: assets/fonts/Roboto-Bold.ttf
          weight: 700
    - family: Noto Sans Gujarati
      fonts:
        - asset: assets/fonts/NotoSansGujarati-Regular.ttf
          weight: 400
        - asset: assets/fonts/NotoSansGujarati-SemiBold.ttf
          weight: 600
        - asset: assets/fonts/NotoSansGujarati-Bold.ttf
          weight: 700
    - family: Noto Sans Devanagari
      fonts:
        - asset: assets/fonts/NotoSansDevanagari-Regular.ttf
          weight: 400
        - asset: assets/fonts/NotoSansDevanagari-SemiBold.ttf
          weight: 600
        - asset: assets/fonts/NotoSansDevanagari-Bold.ttf
          weight: 700
  3. Add the iconsUse the Rounded set at weight 400. Don't use Flutter's built-in Icons.*_rounded; that older set looks different.
    pubspec.yaml
    dependencies:
  material_symbols_icons: ^4.0.0
    Dart
    Icon(Symbols.search_rounded, weight: 400)
  4. Wire up the themeLight and Dark follow the phone's setting.
    Dart
    MaterialApp(
  theme: AppTheme.light(),
  darkTheme: AppTheme.dark(),
  themeMode: ThemeMode.system,
);

    AppTheme also sets 48 px touch targets, the scrim and rounded top corners for every modal bottom sheet, and a drag handle on every modal sheet.

  5. Use tokens, never raw values
    Dart
    Container(
  padding: const EdgeInsets.all(AppSpacing.s16),
  decoration: BoxDecoration(
    color: context.colors.bgSurfaceRaised,
    borderRadius: AppRadius.all(AppRadius.r12),
    border: Border.all(color: context.colors.borderSubtle),
    boxShadow: AppShadows.sm,
  ),
  child: Text(
    'Satsang — Adalaj',
    style: AppTypography.bodyMdStrong.copyWith(color: context.colors.textPrimary),
  ),
);

Regenerating the theme

Terminal
# from the unzipped package
python3 tools/generate.py tools/tokens.json lib/theme
dart format lib/theme

The generator needs only Python 3. tokens.json is exported from the Figma variables; when the design changes you receive a new one.
